CEMENT FENCE POLES WEBSITE

How to run:
1. Extract this ZIP file.
2. Open the cement_poles_project folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.

Files:
- index.html: Telugu website content and sections
- style.css: responsive page styling
- script.js: mobile menu and footer year
- images/: generated field fencing image and supplied reference poster

Notes:
- The phone number 8978639527 was copied from the supplied poster.
- Update the phone number in index.html if it changes.
- Prices and delivery promises are not displayed because they were not provided.
- The website uses a Google Fonts import; an internet connection is needed for those fonts.
